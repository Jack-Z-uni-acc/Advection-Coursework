# Numerics_CW1

Advection assignment. Jack Zanker j.zanker@imperial.ac.uk. Code to solve the advection equation. advection.py: Run this to save snapshots of results of the FTBS, FTCS, CTCS and Spectral method, as well as error plots relative to gridsize and timestep.

advectionHelpers.py: Functions for initialising and calculating l2 error norm schemes.py: FTCS, FTBS, CTCS and Spectral advection schemes.
